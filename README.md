**Advanced security vulnerability management and tracking system** developed by **Muslim Hacker Community**

A comprehensive tool for managing, tracking, and executing security vulnerability exploits with both CLI and web interface support.

## 🌟 Features

### 🎯 Core Functionality
- **CVE Management**: Add, edit, delete, and search CVE entries
- **Multiple Sources**: Support for local files, directories, and Git repositories
- **Automated Execution**: Run multiple exploits against targets with customizable commands
- **Web Interface**: User-friendly GUI for easy management
- **CLI Support**: Powerful command-line interface for automation

### 🔧 Technical Features
- **JSON Database**: Structured storage of CVE metadata
- **Pagination**: Efficient browsing of large CVE collections
- **Search Functionality**: Quick search across CVE database
- **Template Commands**: Dynamic command substitution with placeholders
- **Multi-threading**: Concurrent execution of multiple tools
- **Git Integration**: Direct cloning of exploit repositories
